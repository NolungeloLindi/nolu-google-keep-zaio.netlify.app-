Google Keep-style Note App

A simplified Google Keep-style Notes App built using **HTML, CSS, and JavaScript**. The application allows users to create, view, edit, search, archive, restore, and delete notes.

## How to Run the Project

### 1. Download or Clone the Project

Download the project files to your computer, or clone the repository using Git:
git clone https://github.com/your-username/google-keep-clone.git

### 2. Open the Project in VS Code

Open **Visual Studio Code** and select:

**File → Open Folder**

Choose the project folder:
google-keep-html-css-js

### 4. Check the Project Files

Make sure all four main files are present:

* index.html – Contains the structure of the application.
* css/style.css – Contains the styling. 
* responsive.css - Responsive design.
* js/script.js – Contains the application's functionality.

### 4. Run the Application

The recommended method is to use the **Live Server** extension in VS Code.

1. Open index.html.
2. Right-click anywhere inside the file.
3. Select **Open with Live Server**.
4. Your default web browser will open the application.

### 5. Using the Application

Once the application is open, you can:

* Click **"Take a note..."** to create a new note.
* Enter a title and note content.
* Click **"Save Note"** to add the note.
* Double-click an existing note to edit it.
* Use the **Archive** button to archive a note.
* Open **Archive** from the sidebar to view archived notes.
* Move notes to **Trash** using the delete button.
* Restore notes from the Trash.
* Permanently delete notes from the Trash.
* Use the **Search** bar to find notes.
* Use the **Dark Mode** button to switch between light and dark themes.

### 6. Data Storage

The application uses the browser's **localStorage** to save notes.
This means that notes can remain available after refreshing or reopening the page in the same browser.
No database or server is required to run this project.

## Technologies Used

* **HTML5** – Application structure and semantic elements
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Note creation, editing, searching, archiving, and deletion
* **localStorage** – Saving notes in the browser
* **Google Fonts** – Roboto font
* **Material Icons** – Interface icons
